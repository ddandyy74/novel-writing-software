# UI/UX 设计阶段

## 项目背景

**项目名称**：网文作者码字软件  
**核心功能**：实时保存、长文本撤销、错别字检测、AI 大纲、多平台发布  
**设计原则**：界面简洁、专注于写作、多种主题

## 当前输入

- PRD 文档
- 系统架构设计
- 用户研究成果
- 非功能需求（启动 <3s、保存 <100ms）

## 任务说明

1. 设计编辑器核心界面
2. 设计写作流程交互
3. 设计主题系统（护眼模式、夜间模式）
4. 设计分屏写作（大纲与正文对照）
5. 设计快捷键系统

## 调用的 Agent

按顺序调用以下全局 Agent：

### 1. UX Researcher
```
@ux-researcher 根据用户研究成果，定义网文作者的核心写作流程和痛点场景
```

**应输出**：
- 用户旅程地图
- 核心写作流程
- 痛点场景列表

### 2. UX Architect
```
@ux-architect 设计写作软件的核心交互流程、分屏写作模式、快捷键系统
```

**应输出**：
- 交互流程图
- 分屏设计方案
- 快捷键规范

### 3. UI Designer
```
@ui-designer 设计编辑器界面、主题系统（护眼模式、夜间模式）、组件库
```

**应输出**：
- UI 设计稿（Figma/Sketch）
- 主题配色方案
- 组件设计规范

### 4. Frontend Developer（技术可行性评估）
```
@frontend-developer 评估 UI 设计的技术可行性（Electron/Tauri + CodeMirror）
```

**应输出**：
- 技术可行性评估
- 组件技术方案
- 性能优化建议

## 设计重点

根据需求文档，以下功能需要特别关注 UI/UX：

### P0 功能
- **实时自动保存**：保存状态指示器、离线/在线状态切换
- **长文本撤销**：撤销历史可视化、版本对比界面

### P1 功能
- **错别字检测**：实时标注、批量检测界面、一键修正交互
- **AI 大纲生成**：大纲面板设计、大纲与正文对照
- **多平台发布**：发布状态面板、平台账号管理

### P2 功能
- **AI 封面生成**：封面生成界面、风格选择、预览与导出

## 验收标准

- [ ] UI 设计覆盖所有 P0/P1 功能
- [ ] 交互流程符合用户研究结论
- [ ] 至少 3 种主题方案
- [ ] 快捷键系统提升写作效率
- [ ] 设计方案技术可行
