## 技术亮点

### 1. 混合检测方案

```
用户请求 → 本地模型快速检测
                ↓
          云端 API 深度检测
                ↓
          失败自动降级
```

### 2. 智能缓存策略

- 大纲缓存: 1 小时
- 封面缓存: 24 小时
- 减少重复 API 调用

### 3. 错误处理机制

- 失败重试: 最多 3 次
- 自动降级: 云端 → 本地
- 超时控制: 防止长时间等待
