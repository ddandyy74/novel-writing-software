# 前端重构：免登录基础功能

## 背景

当前应用打开后强制要求登录，未登录用户无法使用任何功能。

**目标**：程序打开后默认无需登录即可使用基础编辑功能（写字、自动保存、撤销），登录后才能使用高级功能。

---

## 设计决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 本地存储方案 | LocalStorage | 容量 ~5MB，足够存储多篇小说，实现简单，适合快速 MVP |
| 登录后数据同步 | 自动同步 | 用户无感知，登录后自动将本地作品上传到云端 |
| 登录入口位置 | 侧边栏底部 | 类似移动端设计，不占用顶部工具栏空间 |
| 高级功能显示 | 显示但置灰 | 用户知道有哪些功能，点击时提示"请先登录" |

## 组件设计

### FeatureGate 组件

**用途**：统一处理需要登录的功能

**Props**：
```typescript
interface FeatureGateProps {
  feature: string;              // 功能名称（用于提示）
  children: React.ReactNode;    // 需要门控的组件
  disabled?: boolean;           // 额外的禁用条件
}
```

**行为**：
- 未登录：子组件置灰，点击弹出登录提示
- 已登录：正常渲染子组件

**使用示例**：
```tsx
<FeatureGate feature="AI大纲生成">
  <button onClick={generateOutline}>AI 大纲</button>
</FeatureGate>
```

---

### LoginPrompt 组件

**用途**：提示用户登录

**Props**：
```typescript
interface LoginPromptProps {
```

**行为**：

## 数据同步设计

### syncLocalToCloud() 流程

```
登录成功
  ↓
读取 localWorkStore 中的所有作品
  ↓
遍历每个作品：
  1. 创建云端作品（API）
  2. 遍历作品的每个章节：
     - 创建云端章节（API）
  3. 更新本地作品的云端 ID
  ↓
清空 localWorkStore（可选）
  ↓
切换到云端数据源（workStore）
  ↓
完成同步
```

### 冲突处理策略

**简单策略（MVP）**：
- 本地数据直接上传，不检查云端是否有同名作品
- 用户可在云端手动整理（删除重复、合并等）

**优化策略（未来）**：
- 检查云端是否有同名作品
- 提供合并/覆盖选项
- 版本对比与冲突解决

## 实施计划

### Phase 1：本地数据层

**目标**：支持未登录用户在本地创建和管理作品

**任务**：
1. 新增 `localWorkStore.ts`
2. 重构 `workStore.ts` 支持双数据源
3. 添加 `isAuthenticated` 判断逻辑

**验收**：
- 未登录用户可以创建作品和章节
- 数据持久化到 LocalStorage
- 刷新页面后数据不丢失

---

### Phase 2：UI 重构

**目标**：支持未登录状态下的完整 UI

**任务**：
1. 重构 `App.tsx`（移除强制登录）
2. 重构 `Main.tsx`（支持未登录状态）
3. 重构 `Login.tsx`（改为 Modal）

**验收**：
- 打开应用无需登录即可进入主界面
- 未登录状态显示"登录/注册"按钮
- 登录按钮点击后弹出登录对话框

---

### Phase 3：功能门控

**目标**：区分基础功能和高级功能

**任务**：
1. 新增 `FeatureGate.tsx`
2. 新增 `LoginPrompt.tsx`
3. 在 `Main.tsx` 中添加高级功能按钮
4. 使用 `FeatureGate` 包裹高级功能

**验收**：
- 未登录时，高级功能按钮置灰
- 点击高级功能按钮弹出"请先登录"提示
- 已登录时，高级功能按钮正常可用

---

### Phase 4：数据同步

**目标**：登录后自动同步本地数据到云端

**任务**：
1. 实现 `syncLocalToCloud()` 方法
2. 登录成功后自动触发同步
3. 同步完成后切换到云端数据源

**验收**：
- 登录后，本地作品自动上传到云端
- 同步过程中显示加载状态
- 同步完成后，数据源切换到云端

## 风险与缓解

### 风险 1：LocalStorage 容量限制

**风险**：LocalStorage 约 5MB，可能无法存储大量作品

**缓解**：
- 显示本地存储使用量
- 超出容量时提示用户登录并同步到云端
- 未来支持 IndexedDB 或本地文件系统

---

### 风险 2：同步失败

**风险**：网络问题导致同步失败

**缓解**：
- 同步失败时保留本地数据
- 提供手动重试选项
- 显示同步状态（成功/失败/进行中）

---

### 风险 3：数据冲突

**风险**：本地和云端有同名作品

**缓解**：
- MVP 阶段：直接上传，不检查冲突
- 未来：提供合并/覆盖选项

---

## 未来优化

1. **IndexedDB 支持**：支持更大容量的本地存储
2. **离线编辑**：支持离线编辑，联网后自动同步
3. **版本历史**：支持查看和恢复历史版本
4. **多设备同步**：支持多设备间的数据同步
5. **冲突解决**：提供智能的冲突检测和解决机制
