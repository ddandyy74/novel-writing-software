### 2.2 实时自动保存（P0）

#### 本地保存
- [ ] 未登录状态下可自动保存到 LocalStorage
- [ ] 保存状态提示（已保存/未保存）
- [ ] 保存延迟 ≤ 100ms
- [ ] 刷新页面后数据不丢失

#### 云端保存（需登录）
- [ ] 登录后可保存到云端
- [ ] 保存状态提示
- [ ] 云端保存成功率 ≥ 99%
- [ ] 离线状态可继续写作

#### 自动保存验证
- [ ] 输入字符后自动触发保存（300ms debounce）
- [ ] 保存过程无感知
- [ ] 保存失败有错误提示

### 2.3 长文本撤销功能（P0）

#### 撤销功能
- [ ] 支持 Ctrl+Z 撤销
- [ ] 支持 Ctrl+Shift+Z 重做
- [ ] 撤销步数 ≥ 50 步
- [ ] 每步可包含最多 2000 字的内容变更
- [ ] 撤销操作即时响应（≤ 200ms）

#### 撤销历史
- [ ] 撤销历史记录可见（可选功能）
- [ ] 可选择性恢复到任意历史版本（可选功能）
- [ ] 版本历史对比功能（可选功能）
